## Архитектурно-значимые требования (ключевые для проектирования)

### Критичные решения:

1. **API Gateway** (D, SEC) - Единая точка входа, защита АБС от перегрузки, rate limiting
2. **Микросервисная архитектура** (S, D) - Постепенная миграция от монолита, начиная с депозитов
3. **Event-driven архитектура** (D, IF) - Замена batch на real-time через Kafka/RabbitMQ
4. **Кэширование** (P) - Redis для справочных данных, снижение нагрузки на БД АБС
5. **Отказоустойчивость** (R, PH) - 99.9% uptime, active-active ЦОД, репликация
6. **Шифрование** (SEC, L) - TLS для трафика, шифрование ПДн в БД (152-ФЗ)
7. **Real-time обработка кредитных заявок** (F, P) - Из batch раз/сутки до < 4 часов
8. **Горизонтальное масштабирование** (P, PH) - Stateless сервисы, балансировка, контейнеры

### Выявленные компромиссы:

| Противоречие | Решение |
|--------------|---------|
| Kafka нужен, но интернет-банк несовместим | Kafka для новых микросервисов, RabbitMQ как временная альтернатива |
| АБС перегружена, но нужна интеграция | API Gateway с rate limiting + кэширование + буферизация через очереди |
| Нужен real-time, но сейчас batch раз в день | Event-driven + CDC (Change Data Capture) из АБС + новые API |
| Скоринг нельзя перегружать | Batch-предрасчеты в ночное время + rate limiting + кэширование результатов |
| Новые технологии vs экспертиза | Использовать знакомые технологии (.NET, Java) с современными подходами |

### Приоритизация (MoSCoW):

**Must Have (MVP):**
- Подача заявок депозиты/кредиты (сайт + интернет-банк)
- СМС-подтверждения
- Управление ставками депозитов
- API Gateway для защиты АБС
- Шифрование TLS
- Соответствие 152-ФЗ, 115-ФЗ, ЦБ РФ

**Should Have (после MVP):**
- Предодобренные кредитные предложения
- Real-time обработка кредитных заявок (< 4 часов)
- Микросервисная архитектура
- Отказоустойчивость (active-active ЦОД)
- Kafka/RabbitMQ для асинхронности

**Could Have (будущие итерации):**
- Полная автоматизация депозитов без бэк-офиса
- CI/CD пайплайны
- Kubernetes
- Webhook API

**Won't Have (не в этом релизе):**
- Полностью онлайн онбординг новых клиентов
- GraphQL API
- CQRS паттерн
